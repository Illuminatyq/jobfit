# BUG-005: get_logger сбрасывал уровень логирования на INFO

- Severity: minor
- Status: fixed
- Компонент: src/jobfit/logging_config.py
- Обнаружен: ревью агентского кода, этап 0

## Симптом
Любой вызов get_logger() затирал выставленный DEBUG/WARNING уровнем INFO.

## Причина
get_logger() вызывал setup_logging() с дефолтным INFO, и ветка
"уже настроено" безусловно делала setLevel(level).

## Фикс
level стал optional (None): уровень меняется только при явной передаче.

## Регрессия
tests/unit/test_logging.py::test_get_logger_does_not_reset_level
